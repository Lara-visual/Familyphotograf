# Лендинг «Андрей Демидов — семейный фотограф»

Готовый статичный лендинг по ТЗ: тёплый премиум-минимализм, мобильная версия в приоритете,
фото — главный элемент страницы.

## Как открыть

Двойным кликом по `index.html` — сайт работает без сборки и интернета.

Если хочется проверить так же, как на хостинге (и чтобы точно работали шрифты и WebP):

```bash
python -m http.server 8000
# затем открыть http://localhost:8000
```

## Что внутри

```
index.html                  страница
privacy.html                политика конфиденциальности (демо-текст)
assets/
  css/styles.css            все стили, палитра и типографика — в :root
  js/main.js                меню, табы, карусель, модалки, форма, видео-превью
  fonts.css + fonts/        Manrope, Inter, Caveat (локально, без Google Fonts)
  img/                      фотографии: .webp + .jpg (fallback)
  raw/                      исходники генерации и служебные файлы (можно удалить)
```

## Что заменить перед публикацией

1. **Контакты** — в `index.html` отмечены комментариями `<!-- ЗАМЕНИТЬ -->`:
   телефон в шапке, мобильном меню и футере, e-mail, ссылки на Instagram и ВКонтакте.
   Те же контакты продублированы в `privacy.html`.
2. **Фотографии** — заменить файлы в `assets/img/`, сохранив имена и пропорции:

   | Файл | Размер | Пропорции |
   |---|---|---|
   | `hero-main` | 1080×1350 | 4:5 |
   | `baby-1…4`, `kid-1…4`, `family-1…4` | 760×950 | 4:5 |
   | `mama-1…3` | 760×950 | 4:5 |
   | `avatar-anna`, `avatar-ekaterina`, `avatar-olga` | 160×160 | 1:1 |
   | `about-andrey` | 760×950 | 4:5 |
   | `video-poster` | 1280×720 | 16:9 |

   Каждой картинке нужны две версии: `.webp` (основная) и `.jpg` (fallback).
   Alt-тексты — в `index.html`, они описывают сюжет кадра.
3. **Видео со съемки** — блок в портфолио временно скрыт: `<figure class="video" hidden>`.
   Чтобы вернуть, уберите атрибут `hidden` в `index.html`. Сейчас вместо ролика
   внутри аккуратное превью-слайдшоу (реального видео не было). Когда появится ролик,
   замените блок `.player` в модалке `#video-modal` на:

   ```html
   <video class="player" controls playsinline poster="assets/img/video-poster.jpg">
     <source src="assets/video/family.mp4" type="video/mp4">
   </video>
   ```

   и удалите вызов `startPlayer()` в `main.js`.
4. **Форма заявки** — подключена к Google Apps Script и пишет заявки в Google Таблицу
   (лист «Заявки»). Код приёмника лежит в `booking/apps-script.gs`, адрес — в
   `assets/js/main.js`:

   ```js
   const BOOKING_ENDPOINT = 'https://script.google.com/macros/s/.../exec';
   ```

   Формат отправки — JSON: `{ name, phone, contact, comment, page, sentAt }`,
   уходит «простым» POST-запросом (`no-cors`, `text/plain`), потому что Apps Script
   не отдаёт CORS-заголовки.

   Если меняете код в Apps Script — не забудьте переразвернуть:
   `Развернуть → Управление развертываниями → карандаш → Версия: Новая версия → Развернуть`.
   URL при этом остаётся тем же.

   Telegram-уведомления отключены: в `apps-script.gs` оставьте `TG_TOKEN` и `TG_CHAT_ID`
   пустыми (`''`) или впишите токен от @BotFather и свой chat_id.
5. **Политика конфиденциальности** — текст демонстрационный, проверьте у юриста.

## Фотоматериал

Все снимки в проекте сгенерированы специально для этого макета (FLUX через Pollinations),
приведены к единой тёплой плёночной цветокоррекции и обрезаны под нужные пропорции.
Это временный визуал: перед публикацией его лучше заменить реальными работами фотографа —
именно они продают съемку. Исходники лежат в `assets/raw/`.

## Технические детали

- Палитра и типографика — CSS-переменные в начале `assets/css/styles.css`.
  Два оттенка чуть темнее исходных из ТЗ, чтобы текст проходил по контрасту 4.5:1:
  кнопки — `--terracotta-cta` (#AF603F вместо #C97B5A), подписи и иконки — `--sage-ink` (#5C6A50 вместо #8A9A7B).
  Акцентный терракотовый #C97B5A остался в декоре: подчёркивание в H1, полоска активного таба, цена.
- Шрифты лежат локально, поэтому страница не зависит от внешних CDN.
- Изображения: `loading="lazy"` для всего ниже первого экрана, `fetchpriority="high"` для hero,
  WebP + JPG fallback, общий вес WebP ≈ 0.55 МБ (самый тяжёлый кадр — 86 КБ).
- Анимации: появление блоков при скролле (IntersectionObserver, 15% видимости),
  hover-увеличение фото, табы, карусель отзывов со свайпом. Всё отключается при
  `prefers-reduced-motion`.
- Доступность: семантическая разметка, alt у фото, клавиатурная навигация по табам,
  ловушка фокуса в модалках, Esc закрывает меню и окна, контраст текста ≥ 4.5:1.
- Адаптив проверен на ширинах 360, 390, 768, 1162 px, горизонтальной прокрутки нет.
